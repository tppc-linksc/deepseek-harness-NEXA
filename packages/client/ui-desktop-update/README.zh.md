# @deepseek-ai/dsh-client-ui-desktop-update

[English](README.md) | 中文

仅用于桌面端的“应用更新”设置页，负责检查、下载、校验并打开 NEXA 应用更新。独立导航入口会直接呈现“检查更新”操作，不再把它藏在“通用设置”中。紧凑布局依次呈现当前版本、自动检查的语义化 switch，以及手动检查操作和紧邻的状态信息，不会把设置弹窗横向撑宽。Host 端不提供运行时行为；浏览器端调用 Electron main 在 `dsh://app` 上提供的私有 `/_desktop/update/*` 路由，在发布状态前校验每个返回字段，并在这些行下方呈现下载进度与后续安装操作。

该包不会从插件配置中直接取得发行 URL，也不会取得本地安装包路径。固定更新源、目标选择、存储、字节限制、SHA-256 校验与打开安装包均由 Electron main 持有。只有桌面 profile 会安装该包。

## 模型体验

无，因为更新设置行及其私有应用路由不会向模型请求增加 prompt、工具、消息或其他值。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **只有已发布的桌面目标可在应用内更新**：当前发行覆盖 macOS arm64、Windows x64 与 Linux x64；其他平台或架构仍可使用应用，但会提示没有可用安装包。
- **安装仍由操作系统接管**：每日自动检查发现新版后会提示；用户确认一次即可下载对应平台安装包、校验 SHA-256 并打开安装程序。Windows 会退出应用并进入安装程序；未签名的 macOS 版本会打开 DMG，用户仍需替换应用后重新启动；Linux 会打开已下载的 AppImage。
- **设置中暂不显示发行说明**：已校验状态带有 GitHub Release 说明 URL，但当前设置行只呈现版本与上游信息。
